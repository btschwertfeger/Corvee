# shell-completion Specification

## Purpose

`corvee completion` prints a shell completion script. Completion offers real ids and label names so a mistyped argument surfaces before the command runs, without a second completion spec to keep in sync.

## Requirements

### Requirement: `completion` prints a shell script
`corvee completion <bash|zsh|fish>` SHALL print the completion function for that shell, generated by click's shell-completion support from the same command and option definitions the CLI uses. That covers subcommand names, flag names, and `click.Choice` values.

#### Scenario: Enable in bash
- **WHEN** `eval "$(corvee completion bash)"` runs in a bash session
- **THEN** pressing tab after `corvee ta` completes `task`

### Requirement: Id arguments complete against real ids
Id arguments SHALL complete against real `TASK-<n>`, `TASK-GLOBAL-<n>`, `FACT-<n>`, and `FACT-GLOBAL-<n>` ids, merged across local and global the way `--scope all` merges. This SHALL apply to every command that takes an id and to every option whose value is a task id (`--parent`, `--blocks`, `--blocked-by`, `--relates-to`, and the `--after` cursor).

#### Scenario: Completing a task id
- **WHEN** local tasks `TASK-1` and `TASK-2` exist and the shell completes `corvee task show TASK-`
- **THEN** both are offered

### Requirement: Label options complete against local labels
Label-valued options (`--label` on `task add`, `task list`, and `task ready`, and `--add` and `--remove` on `task label`) SHALL complete against the local project's real label names, never merged across scope.

A mistyped label otherwise matches nothing without an error.

#### Scenario: Completing a label
- **WHEN** the local project has a label `api` and the shell completes `corvee task list --label a`
- **THEN** `api` is offered

### Requirement: Completion is read-only and silent on failure
Completion SHALL be read-only. Outside a project directory, or against a database on a newer schema than the binary, it SHALL offer no completions and SHALL NOT print an error into the shell's prompt.

#### Scenario: Outside a project
- **WHEN** the shell completes `corvee task show ` in a directory with no project and no global database
- **THEN** no completions are offered and nothing is printed
